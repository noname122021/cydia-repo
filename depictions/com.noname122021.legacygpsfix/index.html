iOS 5.0 – 5.1.1
Should work (experimental)
Features
  • GPS Week Number Rollover Fix: Corrects GPS timestamp date calculations (+1024 weeks) on legacy Qualcomm and Broadcom basebands.
  • Autonomous & On-Demand A-GPS: Embedded offline Qualcomm XTRA ephemeris cache with automatic HTTP fallback, bypassing expired TLS certificates.
  • Precision Navigation Filters: Eliminates stationary drift (SiRF-style), suppresses unrealistic velocity spikes, and smoothes location paths.
  • Fake GPS Location Override: Built-in coordinate spoofer (defaults to Apple HQ Cupertino), ideal for Wi-Fi-only devices and testing.
  • Antenna Calibration: Fine-tune local antenna meter offsets directly in Settings > LegacyGPSFix.
