GPS Rollover Fix, Autonomous A-GPS & Navigation Filters
Совместимость / Compatibility
iOS 6.0 – 6.1.6
Поддерживается / Fully Supported
iOS 5.0 – 5.1.1
Должно работать / Experimental
Примечание: Твик изначально разработан и всесторонне протестирован на iOS 6. Для iOS 5 добавлены необходимые патчи смещений ядра locationd и перехватчиков сетевых запросов A-GPS — функционал должен работать исправно.
Функции / Features
  • GPS Week Number Rollover Fix: Автоматическая коррекция таймстампов GPS (+1024 недели) на старых чипах baseband Qualcomm и Broadcom.
  • Автономный и On-Demand A-GPS: Встроенный оффлайн кэш эфемерид Qualcomm XTRA с автоматическим HTTP-зеркалированием в обход устаревших SSL/TLS сертификатов.
  • Фильтры навигации: Подавление дрейфа координат при неподвижности (SiRF Static Navigation), защита от телепортаций и сглаживание трека.
  • Подмена координат (Fake GPS): Возможность задавать фиксированные координаты (по умолчанию Apple HQ) для устройств без сотового модуля (Wi-Fi iPad / iPod touch).
  • Калибровка антенны: Смещение позиции с точностью до метра прямо из настроек.
