PerfHUD
Real-time performance overlay & CLI telemetry for iOS 6
Features
  • CADisplayLink FPS: Direct screen-refresh frame rate with dynamic color alerts.
  • CPU & Cores: Real-time overall load plus individual core utilization sparklines. Dynamic single-core mode on iPhone 4 (A4).
  • RAM Breakdown: Sub-megabyte precision (e.g. 240.35M) with dedicated tall auto-scaling sparkline and stacked Wired/Active/Inactive/Free memory bar.
  • Network Speeds: Zero-overhead Darwin network stack reading (Download/Upload rates & incoming sparkline).
  • NAND Disk I/O: Hardware disk read/write throughput via IOKit and available storage with percentage bar.
  • Hide / Peek & Corner Jump: Tap to hide behind the screen edge for 2 seconds leaving a thin tab, or cycle clockwise between corners.
  • Zero-Overhead CLI: Includes /usr/bin/perfhud-cli for streaming real-time metrics remotely over SSH from shared RAM.
Changelog
  • v1.1.1

  • v1.1.0
    Added hardware NAND disk read/write metrics (IOKit) and network throughput. Added Hide/Peek tap mechanic with 2s auto-return. Added per-metric toggles in Settings with automatic HUD height scaling and CPU optimization.
  • v1.0.0
    Initial release with FPS, CPU per-core load, RAM sub-MB tracking, stacked memory bar, and perfhud-cli telemetry.
